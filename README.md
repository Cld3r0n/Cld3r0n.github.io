# 🌐 Portfolio web · Adrián Calderón

Código de mi portfolio de ciberseguridad, publicado en **[cld3r0n.github.io](https://cld3r0n.github.io)**.

👤 Para saber más sobre mí, visita mi [perfil de GitHub](https://github.com/Cld3r0n).

## 🎮 Dos formas de ver mi CV

- **Web clásica:** sobre mí, proyectos, skills, formación y contacto.
- **Oficina SOC:** un pequeño juego 2D en el navegador. Creas tu avatar y el mío te presenta el CV zona por zona, con bocadillos y voz opcional. Incluye una terminal interactiva (prueba `help` o `sudo contratar` 😉).

## 🛠️ Sobre esta web

- Diseñada por mí y desarrollada con ayuda de IA.
- HTML, CSS y JavaScript, sin frameworks.
- Alojada en GitHub Pages.
- Todo el contenido sale de un único archivo: `assets/data.js`.
